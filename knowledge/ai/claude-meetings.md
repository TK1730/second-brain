# Claude Meetings（ベータ）を会議で使う

Claude がビデオ通話に参加者として加わり、会話を追いながら会議中に作業する機能「Claude Meetings」の使い方をまとめる。
内容は Anthropic の記事「Introducing Claude Meetings, now in beta」（2026-11-12 公開）[^claude-article] の要約である。
ベータ版のため、仕様、対応範囲、料金は変わりうる。使う前に最新の案内を確かめる。

## できること

- 参加者として通話に表示される。チームは声またはチャットで質問でき、回答は既定で文章になる。
- 会議中に、議論をもとにしたドキュメントやホワイトボードなどの成果物をチームと一緒に作る。
- 接続済みのツールを、依頼した本人の許可の範囲で使う。
- 会議後に、メモ、アクションアイテム、成果物を claude.ai の会議ページにまとめる。過去の会議についても後から質問できる。
- claude.ai のカレンダーから、次回の会議に Claude を追加できる。

## 会議での頼み方

記事の例は、顧客向けイベントの計画会議である。

- 「計画用のドキュメントを作って」と頼むと、ここまでの議論が文書になり、招待されたメンバーが編集しながら話を続けられる。
- 「昨年のイベントの費用は」と聞くと、Claude は検索の承認を求め、結果を通話チャットに投稿して現在の計画と比べる。
- ホワイトボードにスケジュールを書くよう頼むと、ドキュメントと並行して作業できる。
- 終了前に、会議の要約をチームへ共有するよう頼む。

## プライバシーと管理

- 会議ごとに claude.ai の専用ページができ、メモ、文字起こし、成果物が入る。招待された組織内のメンバーが閲覧・編集でき、組織内の他者へ共有もできる。
- 保存されるのは文字起こし、要約、画面の説明である。音声は保存されない。
- 既定では、組織外の人が招待された会議には参加せず、途中で外部の人が加わると退出する。管理者は外部ゲストのいる通話への参加を許可できる。その場合、Claude は通話チャットに告知を出すが、返信はしない。ゲストの発言もメモと文字起こしに含まれる。
- ツールの利用は初回に許可を確認し、一度許可すると以後は有効になる。音声で頼まれたときは、誰が話しているかを毎回確認する。通話チャットに投稿した回答は、全員から見える。
- Claude を追加する前、または自動参加を有効にする前に、全員が文字起こしに同意しているか確かめる。

## 提供条件

| 項目             | 内容                                                                                              |
| :--------------- | :------------------------------------------------------------------------------------------------ |
| 対象プラン       | Team と Enterprise（ベータ、順次展開）                                                            |
| 対応プラットフォーム | Google Meet のみ。ほかは近日対応                                                              |
| 有効化           | Team は既定で利用可能（管理者が無効化できる）。Enterprise は管理者が組織全体または一部に有効化する |
| 利用できない組織 | ベータ期間中は、ZDR、HIPAA 対応構成、CMEK を使う組織                                              |
| 料金（ベータ中） | メモ、文字起こし、通話中の回答は無料。接続済みツールを使った回答はプランの利用量に含まれる。ドキュメントやホワイトボードなどの成果物は 2027-02-10 まで無料 |

- 文字起こしを既存ツール（Gong、Attention、Granola、Fireflies.ai、Otter、Plaud）へ送る連携が近日中に予定されている。
