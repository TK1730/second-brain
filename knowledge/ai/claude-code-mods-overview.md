# Claude Code のモッドで何ができるか、チームでどう管理するか

Claude Code のモッド（mod）の概要と、チームで導入するときの管理、注意点、始め方をまとめる。
内容は Anthropic の公式記事「Customize Claude Code with mods」（2026-10-01 公開）[^claude-article] の要約である。
作り方の詳細（コード構造、サンプル実装）は [別の記事の要約](/knowledge/ai/claude-code-mods.md) に任せ、ここでは扱わない。

## モッドとは

- TypeScript で書く小さな機能で、Claude Code の挙動や見た目を変える。
- Claude Code は、ツールの呼び出し、権限の要求、画面の一部の描画といった動作のたびにイベントを出す。モッドはそのイベントにフックし、イベントの前、後、または代わりに処理を差し込める。
- モッドはプラグインに入れて配布するため、インストールも共有も他のプラグインと同じ扱いになる。
- CLI でもデスクトップアプリでも動く。自分で書いても、Claude に書かせてもよい。
- 背景には、リリースを待たずに細かく制御したいという開発者の要望がある。従来のフックは一部の挙動に影響できるだけで、イベントの書き換え、画面の描画、機能の置き換えはできなかった。

## できること

- モデルに届く前にプロンプトを書き換える。
- ツール呼び出しを止める、書き換える、再試行する。
- 権限の要求を承認または拒否する。
- ツールの出力から秘密情報を取り除き、Claude が読む前に隠す。
- ツール結果や Claude の質問など、画面の要素を編集または置き換える。
- ボタンや入力欄を足し、他のモッドから反応させる。
- 対象をターミナル、デスクトップアプリ、またはその両方に絞る。

同じイベントに複数のモッドがフックしたときは、読み込み順に動く。最初に読み込まれたモッドがイベントを最初に受け取り、最終結果を最後に受け取る。
Claude 自身が、セッション内でモッドを書き、インストールし、ホットリロードすることもできる。

## 記事が挙げる使用例

| 例               | 内容                                                                   |
| :--------------- | :--------------------------------------------------------------------- |
| 組み込みの `/diff` | すでにモッドとして実装されている。`/plugin` で無効にするか、自作のものに置き換えられる |
| CI/CD の状況表示 | サイドペインにパイプラインの状態を出し、ビルドの成否で更新する         |
| 本番環境の保護   | 本番の設定に影響するコマンドの前に、確認を必須にする                   |
| 監査ログ         | 最初に読み込んだモッドが、他のモッドの呼び出しを全て記録する           |

Anthropic は、今後も組み込み機能をモッドへ移し、Claude Code 本体をより小さな核にする方針を示している。

## チームでの導入と管理

- モッドは既存のプラグインの管理に従う。管理者はプラグインのマーケットプレイスを許可または禁止できる。
- Team と Enterprise プランでは、オーナーが管理コンソールで設定する。
- Claude API やサードパーティの API プランでは、管理者が管理対象の設定（managed settings）を利用者のマシンへ配布する。
- Team と Enterprise プラン、および managed settings があるマシンでは、組み込みモッド `sec-default`（セキュリティの既定値）が最初に読み込まれる。利用者が入れたモッドが deny ルールを上書きすることを防ぐ。
- 管理者が自前のモッドを先に読み込む構成にするときは、`sec-default` を一覧へ加えて、この制限を保つ。ソースは `anthropics/claude-code` リポジトリで公開されている。

## 注意点

- モッドはサンドボックスで隔離されない。Claude Code 自身と同じ範囲でマシンにアクセスできる。
- 手元のコードを入れるのと同じ感覚で、信頼できる入手元のモッドだけを入れる。
- 読み込み順で結果が変わるため、複数のモッドを併用するときは順序を意識する。
- 管理者は、自前のモッドを先に読み込むと `sec-default` の保護が外れうる点に気をつける。

## 始め方

1. Claude ディレクトリ（claude.ai/directory）から、モッドを含むプラグインを入れる。CLI なら `/plugin` を実行する。
1. 自作するなら、claude.dev の入門ガイドか、code.claude.com の公式ドキュメント（plugins と mods の概要）を読む。
1. 共有するなら、モッドをプラグインとしてまとめ、claude.ai/directory/manage からディレクトリへ申請する。

記事はリリース日（2026-10-01）から CLI とデスクトップアプリで使えると述べているが、必要な最小バージョンは記していない。記事が挙げるコマンドは `/plugin` だけである。
