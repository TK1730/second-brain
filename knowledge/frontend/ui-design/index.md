# UI 設計・画面の状態

- [UI 部品の分け方（Atomic Design）](react-component-classification.md) - UI を Atomic Design の 5 段階で分類する考え方（atoms、molecules、organisms、templates、pages の役割、部分と全体、構造と内容の分離、名前の付け方、mental model としての位置づけ）。
- [定番の UI 部品の名前と探し方](ui-component-names.md) - 定番の UI 部品の名前と別名を知り、作るときにどの資料を見るかを決める考え方（名前は Component Gallery、コードの出発点は shadcn/ui、キーボード操作と ARIA は WAI-ARIA APG、名前の揺れ、似た部品の違い、ARIA を使う前の原則）。
- [画面の状態を漏れなく設計する](ui-states.md) - 1 つの画面が持つ複数の状態を、見た目の状態ごとに漏れなく設計する考え方（UI Stack の 5 状態、Empty の 3 種類、スケルトン、楽観的な操作、見た目の状態を state で切り替える宣言的な UI）。
- [Web の画面を整えるチェックリスト](web-interface-guidelines.md) - Web の画面を仕上げるときに、作業の場面ごとに確かめる項目の一覧（操作、フォーム、動き、レイアウトと内容、性能、見た目、公開前の点検）。
