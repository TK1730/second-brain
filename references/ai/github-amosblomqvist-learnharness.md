# LearnHarness: 状態機械と DAG で能動的学習を強制する AI チューターハーネス

Eero Alvar Amos Blomqvist が公開している GitHub リポジトリ [amosblomqvist/learnharness](https://github.com/amosblomqvist/learnharness) の要約。
一般的なチャットボットのように AI が一方的に正解を解説してしまう受動的な体験を避け、決定論的な状態機械 (State Machine) と有向非巡回グラフ (DAG) を用いて学習者に能動的学習 (Active Learning) を強制する AI チューターハーネスの設計をまとめている。

## 概要

- **ローカルファースト & BYOK**: 難解な専門分野の学習を支援するために TypeScript で構築されたローカルファーストのアプリケーションであり、BYOK (Bring Your Own Key) 方式で 30 以上の LLM 推論プロバイダに対応している。
- **能動的学習の強制**: 自由形式のチャット UI では、学習者が質問すると AI がすぐに長文の解説を返してしまい、学習者が自分で考える機会が失われやすい。
- LearnHarness はエージェントの周囲に厳格なハーネス (制御構造) を設け、学習者に結果の予測、自分の言葉での言語化、推論過程の明示を要求し、理解が証明されるまで次のステップへ進めない仕組みを実現している。

## 決定論的な 4 フェーズのライフサイクル (State Machine)

学習セッションはプロンプト任せの自由対話ではなく、以下の 4 つのフェーズを持つ決定論的なステートマシンによって制御される。

| フェーズ | 名称 | 主な役割 |
| :--- | :--- | :--- |
| 1 | Measure / Probing (診断・境界検出) | 前提知識を問い、自信度と思考過程から理解が途切れている境界を特定する。 |
| 2 | Plan (計画) | 特定された理解のギャップから学習ゴールへ至る最小の依存関係マップを生成する。 |
| 3 | Teach (教授) | 予測と言語化を求め、理解度チェックに合格するまで先へ進めないゲートを課す。 |
| 4 | Practice (演習) | 別セッションで概念名を伏せた応用問題を出題し、知識の検索と適用を訓練する。 |

### 1. Measure / Probing (診断・境界検出)

- 授業を始める前に、対象トピックの前提知識に関する質問を学習者に投げかける。
- 単なる正誤だけでなく、学習者の回答内容、自己申告の自信度、自由記述による思考過程 (Think out loud) を組み合わせて分析し、「学習者の理解がどこまでは確かで、どこから途切れているか」の境界線を正確に特定する。

### 2. Plan (計画)

- 診断フェーズで明らかになった理解のギャップに基づき、現在の理解状態から目標とする学習ゴールへ到達するための最小限の依存関係マップ (カリキュラム) を生成する。

### 3. Teach (教授)

- 計画されたステップに沿って 1 つずつ授業を進めるが、受動的にテキストを読ませることはしない。
- 解説を提示する前に学習者自身に結果やメカニズムを予測させ、説明の後には理解度チェック (Comprehension Gate) に合格するまで次のノードへ進めないゲートを課す。

### 4. Practice (演習)

- 学習フェーズとは切り離された別セッションで、学んだ概念名をあえて伏せた応用問題を出題する。
- ヒントのない状態からどの知識を使うべきかを自力で思い出す検索練習 (Retrieval Practice) と、未知の問題への適用を訓練する。

## DAG (有向非巡回グラフ) によるカリキュラム管理

- **Mermaid グラフのパースと検証**: `plan_init` フェーズにおいて、制限付きの Mermaid グラフ記法をパースして構造を検証し、各マイルストーン質問を「ノード」、前提知識の依存関係を「エッジ」とする厳密な DAG (有向非巡回グラフ) 構造を保証する。
- **履歴からの決定論的な状態導出**: 各ノードの進捗状態 (`current`、`visited`、`upcoming`) は、LLM が任意に書き換えられる自己申告フラグではなく、追記専用 (append-only) のツール呼び出し履歴と対話状態から決定論的に導出される。
- **動的な再構成**: 教授フェーズの途中で学習者に前提知識の根本的な誤解があることが判明した場合、ハーネスは既存の DAG を動的に再構成し、不足している基礎ノードを挿入してから学習を再開する。

## 永続的なローカルナレッジグラフ

- セッションのすべての記録はローカル環境に JSON Lines (`.jsonl`) 形式で保存される。
- 学習者が各セッションで獲得・証明した命題や推論チェーンは、バックグラウンドの永続的なナレッジグラフとして蓄積される。
- これにより、次回以降の新しいトピックの学習セッションでも、過去に検証済みとなった理解構造をそのまま引き継いで診断や計画に活用できる。
