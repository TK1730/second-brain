# WAI-ARIA Authoring Practices Guide: Patterns 一覧 要約

W3C WAI の ARIA Authoring Practices Guide（APG）の「Patterns」一覧ページと、APG のトップページおよび Read Me First ページの要約である。
外部資料の要約であり、最終的な根拠は原典を参照すること。
要点は「APG は ARIA の意味づけを一般的なデザインパターンやウィジェットに適用する方法を示す」「ARIA は誤って使うと害になるので、使う前に 2 つの原則を理解する」「Patterns ページは 30 のパターンを一行の説明つきで並べる」の 3 つである。
個々のパターンのページ（キーボード操作、ロール、状態、プロパティなど）は、この要約の対象外である。

## APG とは

出典: ARIA Authoring Practices Guide (APG) Home

- APG は、ARIA（Accessible Rich Internet Application）仕様が定義するアクセシビリティの意味づけ（accessibility semantics）を使って、アクセシブルな Web 体験を作る方法を学ぶためのガイドである。
- 一般的なデザインパターンとウィジェットに、アクセシビリティの意味づけを適用する方法を説明する。
- デザインパターンと動作する例を示し、基本的な実践についての詳しい指針で補う。

トップページは、APG の資料として次の 4 つを挙げている。

| 資料                                        | 内容                                                                                                                           |
| :------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------- |
| Design Patterns and Examples                | ARIA のロール、状態、プロパティと、キーボード操作の実装で、アクセシブルな部品を作る方法。各パターンに 1 つ以上の動作例がある。 |
| Use ARIA Landmarks                          | HTML の区分要素と ARIA のランドマークロールで、支援技術の利用者がページのレイアウトの意味を理解しやすくする方法。              |
| Providing Accessible Names and Descriptions | 要素にアクセシブルな名前と、適切な場合は説明を与えること。アクセシブルな Web 体験を作るうえで最も重要な責務の 1 つである。     |
| And So Much More...                         | アクセシビリティの意味づけの正しい使い方、キーボード操作の開発などの基本的な実践。                                             |

## ARIA を使う前の原則

出典: Read Me First > No ARIA is better than Bad ARIA

- ARIA のロール、状態、プロパティは、支援技術にとっての CSS に似た働きをする。
- スクリーンリーダーの利用者にとって、ARIA は非視覚的な体験の描画を制御する。
- 誤った ARIA は視覚的な体験を誤って伝え、対応する非視覚的な体験に重大な悪影響を与えうる。
- ARIA や APG の指針を使う前に、次の 2 つの原則を理解するよう求めている。

1. 原則 1: ロールは約束である。
   - たとえば `<div role="button">` は、その `div` の作者が、ボタンに期待されるキーボード操作を JavaScript で実装した、という約束である。
   - HTML の input 要素と違い、ARIA のロールはブラウザにキーボード操作やスタイルを与えない。
   - 約束を果たさずにロールを使うのは、「注文する」ボタンが注文を取り消してカートを空にするようなものだと例えている。
   - APG の目的の 1 つは、各 ARIA ロールに期待される動作を定義することである。
1. 原則 2: ARIA は覆い隠すことも補強することもでき、力と危険の両方を生む。
   - 覆い隠す例は、元の意味づけや内容を上書きする使い方である。
     たとえば `<a role="menuitem">` は、支援技術の利用者にリンクではなくメニュー項目として知覚される。
   - 補強する例は、元の内容に必要な意味を足す使い方である。
     たとえば `<button aria-pressed="false">Mute</button>` がある。
   - これが ARIA の力であり、同時に危険でもある。
     作者が意図せずアクセシビリティの意味づけを上書きしてしまうことがある。

## ブラウザと支援技術の対応

出典: Read Me First > Browser and Assistive Technology Support

- 本番でこのガイドのコードを使う前に、支援技術との相互運用性をテストすることが不可欠である。
- このガイドは ARIA 1.2 の適切な使い方を示すことが目的である。
  そのため、ブラウザや支援技術の ARIA 1.2 対応の欠落を回避する実装手法は、意図的に説明も実装もしていない。
- 対象とする利用者に関係するブラウザと支援技術の組み合わせごとに、実装を十分にテストするのが望ましい。
- 例の JavaScript と CSS は、執筆時点の最新の Chrome、Firefox、Safari で動くように書かれている。
- ARIA Working Group などの貢献者が見落とした誤りを除き、特定のブラウザや支援技術でうまく動かない例は、そのブラウザや支援技術のバグを示している。
- モバイルとタッチへの対応は、現時点でどの例が対応しているかをガイドは示していない。
  一部の ARIA の機能は、どのモバイルブラウザでも未対応である。

## Patterns 一覧

出典: Patterns

Patterns ページは、パターンを一覧にし、絞り込み（Filter Patterns）で探せるようにしている。
各項目はパターンの名前と一行の説明からなり、次のとおり 30 件ある。

| パターン                                              | 一行の説明                                                                                                                            |
| :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------ |
| Accordion (Sections With Show/Hide Functionality)     | 縦に積まれた対話的な見出しの集まり。各見出しは、節の内容を表すタイトル、内容の抜粋、サムネイルを含む。                                |
| Alert                                                 | ユーザーの作業を妨げずに注意を引く形で、短く重要なメッセージを表示する要素。                                                          |
| Alert and Message Dialogs                             | ユーザーの作業を中断して重要なメッセージを伝え、応答を得るモーダルダイアログ。                                                        |
| Breadcrumb                                            | 現在のページの親ページへのリンクを、階層順に並べたもの。                                                                              |
| Button                                                | フォームの送信、ダイアログを開く、操作の取り消し、削除などの動作やイベントを起こすためのウィジェット。                                |
| Carousel (Slide Show or Image Rotator)                | スライドと呼ぶ項目の集まりを、1 つ以上のスライドの部分集合として順に表示するもの。                                                    |
| Checkbox                                              | WAI-ARIA は 2 種類のチェックボックスを支える。チェック済みか否かの 2 状態のものと、一部チェック済みの第 3 の状態を持つ 3 状態のもの。 |
| Combobox                                              | ポップアップが関連づけられた入力ウィジェット。                                                                                        |
| Dialog (Modal)                                        | 主ウィンドウまたは別のダイアログウィンドウに重ねて表示されるウィンドウ。                                                              |
| Disclosure (Show/Hide)                                | 内容を折りたたむ（隠す）か展開する（見せる）かを切り替えられるウィジェット。                                                          |
| Feed                                                  | ユーザーがスクロールすると、新しい内容の節を自動で読み込むページの一部。                                                              |
| Grid (Interactive Tabular Data and Layout Containers) | 矢印キー、Home、End などの方向キーで、含まれる情報や対話的な要素の間を移動できるコンテナ。                                            |
| Landmarks                                             | ページの主要な部分を識別する 8 つのロールの集まり。                                                                                   |
| Link                                                  | リソースへの対話的な参照を提供するウィジェット。                                                                                      |
| Listbox                                               | 選択肢の一覧を示し、1 つ以上を選べるウィジェット。                                                                                    |
| Menu and Menubar                                      | 動作や機能などの選択肢の一覧をユーザーに示すウィジェット。                                                                            |
| Menu Button                                           | Menu and Menubar パターンで説明するメニューを開くボタン。                                                                             |
| Meter                                                 | 定められた範囲で変化する数値を図で表示するもの。                                                                                      |
| Radio Group                                           | ラジオボタンと呼ぶチェックできるボタンの集まりで、同時にチェックできるのは 1 つまで。                                                 |
| Slider                                                | 与えられた範囲から値を選ぶ入力。                                                                                                      |
| Slider (Multi-Thumb)                                  | Slider パターンを実装しつつ、多くは 1 本のレール上に 2 つ以上のつまみを持つもの。                                                     |
| Spinbutton                                            | 値を、離散的な値の集合または範囲に制限する入力ウィジェット。                                                                          |
| Switch                                                | オンとオフの 2 つの値から 1 つを選ぶ入力ウィジェット。                                                                                |
| Table                                                 | HTML の table 要素と同様に、1 つ以上の行と、各行の 1 つ以上のセルからなる静的な表の構造。対話的なウィジェットではない。               |
| Tabs                                                  | タブパネルと呼ぶ層になった内容の節の集まりで、一度に 1 つのパネルを表示する。                                                         |
| Toolbar                                               | ボタン、メニューボタン、チェックボックスなどのコントロールをまとめるコンテナ。                                                        |
| Tooltip                                               | 要素がキーボードフォーカスを受けたとき、またはマウスが乗ったときに、その要素に関する情報を表示するポップアップ。                      |
| Tree View                                             | 階層的な一覧を示すウィジェット。                                                                                                      |
| Treegrid                                              | 編集や操作ができる表形式の情報からなる、階層的なデータグリッドを示すウィジェット。                                                    |
| Window Splitter                                       | ウィンドウの 2 つの区画（ペイン）の間にある動かせる区切りで、ペインの相対的な大きさを変えられる。                                     |
