# React コンポーネント・状態管理

- [Headless Component で React の UI とロジックを分離する](itnext-decoupling-ui-and-logic-headless-components.md) - Juntao Qiu の記事「Decoupling UI and Logic in React: A Clean Code Approach with Headless Components」の要約。useToggle の抽出と Downshift を例に、振る舞いと見た目を分ける考え方。
- [Headless Component パターン](martinfowler-headless-component.md) - Juntao Qiu の記事「Headless Component: a pattern for composing React UIs」の要約。見た目を持たないコンポーネント（カスタムフック）に状態とロジックを集め、UI と切り離す設計パターン。
- [React: Choosing the State Structure 要約](react-choosing-the-state-structure.md) - React 公式ドキュメント「Choosing the State Structure」の要約（state の構造を決める 5 つの原則、関連する state のまとめ方、矛盾・冗長・重複・深い入れ子の避け方）。
- [React: Managing State 要約](react-managing-state.md) - React 公式ドキュメント「Managing State」（学習の章の概要ページ）の要約（宣言的な UI と見た目の状態、state の構造の選び方、state の持ち上げ、保持とリセット、reducer、context、reducer と context の組み合わせ）。
- [React: Passing Data Deeply with Context 要約](react-passing-data-deeply-with-context.md) - React 公式ドキュメント「Passing Data Deeply with Context」の要約（props の受け渡しの問題、Context の作り方と使い方、同じコンポーネントでの利用と提供、中間コンポーネントの通過、使う前の代替案、使いどころ）。
- [React: Passing Props to a Component 要約](react-passing-props-to-a-component.md) - React 公式ドキュメント「Passing Props to a Component」の要約（props の渡し方と読み方、既定値、スプレッド構文での転送、children による JSX の受け渡し、props の変化と不変性）。
- [React: Sharing State Between Components 要約](react-sharing-state-between-components.md) - React 公式ドキュメント「Sharing State Between Components」の要約（state を共通の親へ持ち上げる 3 つの手順、制御されたコンポーネントと制御されていないコンポーネント、state ごとに 1 つの情報源）。
- [React: Thinking in React 要約](react-thinking-in-react.md) - React 公式ドキュメント「Thinking in React」の要約（モックアップから始める、コンポーネントの階層、静的な版、state の最小表現、state の置き場所、逆方向のデータの流れ）。
- [React: You Might Not Need an Effect 要約](react-you-might-not-need-an-effect.md) - React 公式ドキュメント「You Might Not Need an Effect」の要約（Effect が要らない 2 つの場面、描画中の計算、useMemo、key による状態のリセット、イベントハンドラへの移し方、親への通知、外部ストア、データ取得）。
